## 개별 한계 / Asset-specific limitations

**PASS_WITH_LIMITS. 필수 형상 수정 없음.** 펼친 차량 비상 삼각대의 정적 게임용 시각 소품으로 최종 3 LOD × BLEND/FBX/GLB, 9개 모델이 통과한다. 이 판정은 역사 전체의 신규성, 실제 교통 안전·반사 성능, 물리적 안정성 또는 Unity 인증이 아니다. 최종 전체 백업과 새 복원 검증, 이후 완료 등록은 부모의 다음 단계이며 이번 감사는 업로드·등록을 하지 않았다.
검토 중 실제 BLEND 3개를 다시 열고 FBX/GLB 6개를 기본 설정으로 새로 가져왔다. 생성기에서 다시 만든 이상적 좌표를 검사한 것이 아니다. 가져오기·UV/재질·원시 GLB 읽기는 검토한 제작자 루틴을 재실행했고, 주 교차·체적 검사는 이전 독립 회색 감사의 별도 알고리즘을 9개 새 추출에 적용했다. 교차의 정확 극점과 면적 여부는 다른 vertex/edge 열거 알고리즘과 모든 후보에서 대조했다. 새 재질 순도·회색 저장 배열·바닥 분리·폴리곤 노멀 검사로 보완했다. 모든 코드를 처음부터 새로 작성했다고 주장하지 않는다.
실제 코너 노멀 최대 오차는 LOD별 **0.001366901° / 0.000627761° / 0.000248939°**다. 원시 GLB의 실제 POSITION·NORMAL·인덱스를 직접 읽은 최대 오차는 **0.003750377° / 0.003152838° / 0.003555911°**로 모두 0.01° 미만이다. 실제 폴리곤 노멀도 따로 읽어 같은 기준을 확인했다. 노멀을 보정하거나 불량 요소를 마스킹하지 않았다. 저장 네이티브에는 custom normals·smooth faces·modifiers가 없으며 내보낸 분리 노멀은 가져온 그대로 검사했다.
- 전체 **1,746,000쌍**을 계수했다. 포괄 실제 좌표 AABB로 배제한 1,662,816쌍과 정확 유리수 계산 83,184쌍이 정확히 합산된다. 결함 0건, 두 교차 알고리즘 불일치 0건이다. 자기 쌍, 공유 인덱스 쌍, 부품 쌍을 통째로 제외하지 않았다.
- 실제 고리 전면의 삼각형 연결에서 안팎 두 경계를 재구성했다. 안쪽 경계에서 **0.5%만 안으로 물린 전체 단면**을 실제 전체 깊이보다 앞뒤 20 mm 긴 통로로 연장하고 모든 실제 삼각형을 정확히 잘랐다. 경계 교차가 없고 내부점도 모든 고체 밖이다. 작은 중앙 광선만으로 전체 구멍을 판정하지 않았다. 이 증명은 inset 내부를 대상으로 하며 제외된 얇은 경계 띠까지 인증하지 않는다. 프레임 아래·앞다리 사이·뒷다리 사이의 별도 유한 공간 3개도 통과했다.
상단 맞댐은 매끈하고 후면 연결판은 단순하다. 반사 필드는 사진보다 짧고 좁으며, 미세 프리즘·고무 발 덮개가 없다. 이 차이를 숨기지 않으며 정밀 복제·접힘 동작·동일 반사 면적이나 성능을 주장하지 않는다. 제조사 **430 × 430 mm는 전체 폭·높이에만** 대응한다. 깊이, 프레임 단독 높이, 두께와 뒤쪽·내부 구조는 추정이다. 브랜드·승인 마크·사진 텍스처를 쓰지 않았다.
복원된 NEW554 원본 README와 참조 브리프를 직접 읽었다. 얇은 45°/45°/90° 평면 제도 삼각자와 달리 NEW632는 입식 표지, 이중 띠, 아래 핀과 교차 받침·네 발을 갖춘 완성 물체이므로 단순 색상 변형은 아니다. 그러나 역사 문서 **1,151개 본문 미확보** 제한은 남는다. 전역 신규성 PASS는 하지 않았으며 이후 백업·등록 문서에서도 조건을 유지해야 한다.
검사 전후 선택 9개와 전체 최종 소스, 회색 봉인 파일 및 참조 파일의 해시를 확인했다. 원본 수정·삭제·업로드·인덱스 변경은 없다. 감사 폴더는 6 MiB 이하, 확인된 자산별 연구·제작·감사·회색 백업·새 복원 및 별도 비공개 백업 합계는 512 MiB 이하이고 최소 2 GiB 여유를 유지한다. 정확한 마지막 저장량은 검사 기록을 따른다. 이후 전체 백업·업로드·새 복원 비용은 부모가 별도로 합산해야 한다.
**시각 판정: PASS_WITH_LIMITS. 필수 형상 수정 없음.** 이것은 수치 감사와 별개인 시각 판정이며 최종 등록이나 백업 완료를 뜻하지 않는다.
시각 검토는 보존된 제작자 렌더를 대상으로 했으며 검토자가 78장을 새로 렌더한 것은 아니다. 실제 파일을 다시 여는 렌더 스크립트, 원본 해시, 가져온 실제 좌표의 동일성 검사, Cycles 48 samples 및 디노이저 OFF 설정을 읽었다. 이미지 78개의 실제 해시·크기·해상도와 원본 모델 연결을 별도로 재계산했다. 54개 전체 고립 뷰와 6개 맥락 뷰는 전체 자산이 프레임 안에 들어온다. 상세 뷰 18개는 의도적인 부분 확대다. 수치 검토의 독립 재가져오기와는 구분한다.
앞 사선에서 뒤쪽 발 하나가 가려지는 것은 정상이다. 정면의 검은 받침은 어두운 배경에 묻히는 부분이 있어 모든 단일 뷰에서 네 발이 뚜렷하다고 주장하지 않는다. 밝은 노면 맥락과 측면·아래 시점에서 받침 형태를 확인했다. 접지의 정확성은 그림자만으로 결론 내리지 않고 별도 수치 결과를 따른다.
사진의 실물은 꼭대기와 하부에 접이 부품 이음이 보이지만 모델 상단 맞댐은 거의 매끈하고 작은 후면 연결판도 단순하다. 반사 필드는 실물보다 짧고 좁아 꼭짓점의 민무늬 면적이 크다. 사진의 미세 프리즘과 고무 발 덮개는 없다. 단순화는 실제 화면에서 확인되므로 정밀 복제, 동일 반사 면적 또는 성능을 주장하면 안 된다. 펼친 정적 게임 소품의 용도와 구조는 유지되어 필수 수정 사유로 보지 않는다.
제조사 430 × 430 mm는 전체 폭·높이뿐이다. 깊이 360 mm, 프레임 단독 높이 385 mm, 두께와 뒤쪽·내부 조립은 추정이다. 430 mm를 삼각형 각 변 길이로 바꾸지 않는다. 브랜드·승인 마크·사진 텍스처를 복사하지 않는다. 교통 안전, 질량 중심, 마찰, 바람 저항, 재료 강도 또는 물리적 안정성의 검증은 없다.
