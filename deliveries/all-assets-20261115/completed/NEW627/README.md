## 보존한 실패와 제한 수정
2. 최초 LOD2 생성기에서는 연속 문자열 치환이 서로 다른 치형 높이 오프셋1.6/3.2mm를 둘 다3.2mm로 바꾸었다. 그 결과 원주 표본2구간이 역전되고 가는 원통 면의 float32 노멀 계산이 불안정해졌다. 실제 노멀 최대0.018555°와 GLB 원시 노멀0.018046°로 실패했으며 원본 실패파일·재가져오기·GLB 결과를 모두 보존했다.
회색 단계의 과노출 및 near-clip 실패 이미지도 원래 위치에 그대로 있다. 이번 최종 렌더는 첫 실행부터 카메라 near0.5mm, far10m로 촬영하고 모든 자산 정점이 두 평면 사이에 있는지 기록했다. 최종 렌더의 실패 조명/클리핑 실행은 없었다.

각 선택 파일을 별도로 실제 열고 그 좌표가 해당 검사 추출본과 같은지 확인한 뒤512px8뷰를 만들었다. 대표사선·앞·뒤·왼쪽·위·아래·보어 근접·중앙 톱니 통로 근접으로 총72장이다. LOD별 native에는 별도 검토 배경을 붙여256/512px 갑판 맥락2장씩, 총6장을 추가했다. 배경 갑판은 납품 모델에 들어 있지 않고 숨은 설치 볼트나 체결 완료를 주장하지 않는다.
