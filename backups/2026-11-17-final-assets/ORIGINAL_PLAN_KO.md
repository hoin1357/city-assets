# 침수된 대도시 탐험 게임 · 2,000종 3D 에셋 분류안

작성일: 2026-10-17 · 단계: 제작 전 분류·수량 계획 · 도구: Blender

## 1. 기획 범위
뉴욕에서 연상되는 밀도 높은 대도시의 주거·업무·상업·공공·산업·교통·해안 공간을 구성하고, 그 도시가 바다에 잠긴 뒤 탐험하는 게임을 위한 분류안이다. 실제 뉴욕의 모든 건물이나 지리를 1:1 복제한다는 의미는 아니다. 특정 게임에 종속된 모드가 아니라 독립 게임용 원본 에셋 기획으로 가정한다. 카메라·엔진·시대·해역·침수 후 경과 시간은 아직 미정이다.

총량은 정확히 **2,000종**으로 배분한다. 이는 완성된 모델 수가 아니라 앞으로 제작할 고유 형태 에셋의 예산이다. 각 표의 수량은 그 세부 카테고리 안에서 만들 서로 다른 형태의 개수이며, 예시는 전수 개별 모델 이름 목록이 아니다.

| 영역 | 수량 | 범위 |
|---|---:|---|
| A. 건축 | 600 | 구조, 파사드, 랜드마크, 지붕, 출입구, 실내 건축 |
| B. 도시 외부·교통·인프라 | 500 | 도로, 거리 시설, 대중교통, 차량, 항만·설비, 공원 |
| C. 실내·생활·직업 소품 | 500 | 집, 사무실, 상점, 식당, 공공시설, 작업장, 개인 소지품 |
| D. 수중 생태·폐허·탐험 장치 | 400 | 해조, 동물, 지형, 붕괴 잔해, 수중 조사·발견물 |
| 합계 | **2,000** | 색상 교체 및 단순 크기 변형 제외 |

## 2. ‘모양이 다르다’의 집계 규칙
- 하나의 에셋은 배치 또는 상호작용 단위인 고유 모델이다. 오브젝트가 여러 개여도 한 의자는 1종이다.
- 색상·텍스처·로고·글자만 변경한 모델, 크기만 바꾼 모델, 좌우 반전만 한 모델은 추가 수량으로 세지 않는다.
- 실루엣, 구조, 연결 방식, 구멍·입구, 부피 배치 등의 실질적인 기하 차이가 있어야 별개 형태로 센다.
- 예: 의자는 좌판만 색을 바꾸는 대신 등받이 구조·팔걸이 유무·다리 구조·접이식 관절을 다르게 설계한다.
- 손상형은 표면에 얼룩만 추가하면 신규가 아니다. 차체 압궤·벽 관통·프레임 절단처럼 형상이 달라질 때만 D에서 센다.
- LOD, 충돌체, UV, 재질, 리그, 애니메이션, 파일 포맷별 내보내기는 동일 모델의 제작 결과이며 종수에 중복 가산하지 않는다.
- 기존 부품으로 조립한 주택·상점·거리 프리팹은 추가 종수에 넣지 않는다. 다른 부품에 없는 고유 랜드마크 셸은 A에서 1종으로 센다.
- 잔해 군집은 실제로 새 형상을 만든 고유 메시일 때만 센다. 기존 소품을 위치만 바꿔 묶은 프리팹은 제외한다.
- 동일한 외형이 두 공간에 쓰이면 하나의 ID를 공유한다. 예: 집과 사무실에서 같은 의자를 쓰는 경우 중복 제작·집계하지 않는다.

## 3. 도시 공간 커버리지
- 주거: 브라운스톤 거리, 연립·다세대, 중층 아파트, 고층 주거, 낡은 계단실·지하실.
- 업무·상업: 오피스 블록, 코너 상점, 식당·카페, 슈퍼마켓, 세탁소, 호텔·극장·창고형 매장.
- 공공: 학교, 병원, 도서관, 소방·경찰 시설, 행정 공간, 종교·기념 공간.
- 교통: 격자형 교차로, 보행 골목, 지하철 출입부·승강장, 고가 구간, 버스 정류장, 주차·서비스 구역.
- 산업·해안: 작업장, 창고, 하역장, 부두, 서비스 선박, 배관·전력·배수 설비.
- 자연·침수: 공원, 해저 지형, 해조에 뒤덮인 거리, 붕괴 구역, 실내 퇴적층, 난파물, 조사 장비.

이 공간들은 에셋을 조합해 만드는 장소 프리팹이다. 장소 수를 에셋 수에 다시 더하지 않는다.


# 수몰 탐사 도시용 건축 에셋 분류안: 정확히 600개

뉴욕에서 연상되는 브라운스톤 연립주택, 밀집 주거 블록, 상업가, 계단형 고층 건물, 공공건축, 산업 유산의 공간 리듬을 참고하되, 실존 랜드마크를 복제하지 않는 Blender 3D 에셋 계획이다. **모델링 결과물이 아닌 세부 카테고리·수량 배분안**이다.

## 범위와 집계 원칙

- 합계는 **6개 대분류 / 48개 세부 카테고리 / 600개 고유 형태 에셋**이다. 아래 A001–A048은 개별 모델 ID가 아니라 카테고리 ID이며, 제작 시 A001-01 등의 하위 번호를 부여한다.
- 에셋 1개는 독립적으로 등록·재사용하는 고유 기하 설계 1개다. 단일 메시 또는 문짝과 문틀처럼 기능상 분리된 컬렉션일 수 있지만, 해당 컬렉션의 하위 메시를 다시 여러 에셋으로 세지 않는다.
- 실루엣, 개구 배열, 접합 구조, 지지 방식, 통과 경로 중 하나 이상이 실질적으로 달라야 별도 형태로 센다. 색상·재질·젖음·조명·텍스처·장식 데칼·LOD·충돌 메시·UV·피벗·파일 형식·열림 자세만 다른 버전은 추가하지 않는다. 단순 스케일 조절·좌우 반전·층수 반복도 추가하지 않는다.
- 표의 곱셈은 실제로 다른 구조를 만드는 형태 조합이다. 구현 시 두 조합이 사실상 동일한 메시로 수렴하면 중복 하나를 없애고 다른 고유 구조로 대체해야 한다.
- **전체 조립 건물·거리 블록·완성 프리팹은 부품과 중복 집계하지 않는다.** A017–A024의 66개는 일반 모듈 조합으로 대체되지 않는 고유 핵심 구조 셸만 센다. 이 셸에 A계열 창호·지붕·문 등을 배치한 완성 건물은 추가 1개가 아니다. 셸 내부의 개별 조각 역시 별도 카테고리에서 다시 세지 않는다.
- A009–A016의 파사드는 입체 벽체·개구·조적/구조 리듬이 통합된 전용 메시다. 독립 창호·문·간판은 포함하지 않는다. A001–A008의 기본 부재를 단순 배치한 프리팹이라면 새 파사드 에셋으로 집계하지 않는다.
- **전량 온전한 건축 구조**로 한정한다. 수몰은 배치와 환경 연출 조건이다. 붕괴 벽·바닥 파열·깨진 외벽·낙하 구조물·폐허 잔해·손상 변형은 전부 별도 잔해 영역에 속하며 여기서 제외한다. 의도된 아트리움·개구·계단·셋백은 온전한 구조다.
- 도로·보도·가로등·소화전·교통시설·공공 교량·부두·차량·선박·수중 생물·해조·산호·쓰레기·가구·집기·상품·설비 기계·배관·탱크·간판은 제외한다. 굴뚝과 승강로는 건축 셸만 포함한다.
- 외부 계단·비상계단·연결통로·캐노피는 건물에 직접 결합되는 건축 부속물만 포함한다. A035 창호를 외부와 실내 양쪽에서 사용해도 1개로 센다. 공통 사용 부품은 최초 소유 카테고리 하나에만 배정한다.

- 파손·좌초·찌그러짐·잔해 버전, 건물 건축 요소, 실내 가구·상점 소품, 수중 생물·수중 식생은 이 범위에서 제외한다. 수몰 전 도시에서 자라던 육상 나무·관목의 잔존 줄기와 가지 골격은 B054·B055에 포함한다. 모든 자산은 기본 온전한 형태를 기준으로 하며 수몰 상태는 배치와 셰이딩 단계에서 표현한다.

# 제작 공통 규격과 진행 순서

## 공통 규격 제안
1. 기본 단위는 미터로 맞추고 건축 모듈의 접합 폭·높이·벽 두께를 고정한다. 카메라와 캐릭터 이동 크기를 먼저 시험한 뒤 수치를 확정한다.
2. 지붕·층·외벽을 분리해 실내 진입과 시야 가림 처리에 대응한다. 문·서랍·금고 뚜껑은 동작 가능한 축 위치를 갖게 한다.
3. 해초·따개비·퇴적층은 독립 모델로 만들어 정상 건축·차량·소품에 재사용한다. 부착 조합 자체를 신규 종수로 세지는 않는다.
4. 재질은 석재·벽돌·콘크리트·페인트 금속·녹슨 금속·목재·유리·천·해양 표면 등 공통 계열로 묶는다. 물속 조명 아래 실루엣이 읽히는지 확인한다.
5. 소품·중형 설비·건축·생물마다 다른 복잡도 예산을 둔다. 카메라 거리·타깃 기기·동시 표시량을 모르는 단계에서 모든 모델에 동일한 폴리곤 수를 강제하지 않는다.
6. 형태표 승인 후 세부 ID 아래에 개별 모델 번호를 부여한다. 예: A001_01. 각 모델에는 치수, 특징, 피벗, 상호작용 부품, 충돌 단순화, LOD 필요 여부를 기록한다.
7. 원본 .blend와 게임용 내보내기를 분리한다. GLB·FBX 등의 최종 형식과 축·재질 규칙은 사용할 엔진을 확인한 뒤 확정한다.
8. 실내 탐험용 건물은 외관만 있는 셸이나 가짜 내부 텍스처로 대체하지 않는다. 실제 통로·바닥·출입 공간을 검수한다.
